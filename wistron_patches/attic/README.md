0012 was restored after isolated schema validation on console-2 / port 4
(ES1227-54TS, SONiC 5.2.2 / Debian 12 / kernel 6.1) on 2026-10-21.
The original schema rejects the four PoE PORT fields; adding them accepts
PoE defaults and legacy NA values, preserves round-trip values, and still
rejects values longer than 64 characters. Existing non-PoE PORT data passes.
This verifies schema behavior, not PoE hardware or a Trixie image. The old
patch also modified ignored cvlyang-models output, which is absent in a
fresh checkout; setup.py generates that copy from the source YANG file.

The 2026-10-21 ARM64/Amazon incremental build through build-menu.sh passed.
Bookworm and Trixie source/CVL wheel entries and both host schema copies in
the final BIN were checked for all four fields. When enabling this patch
on an already configured incremental tree, rebuild existing sonic_yang_models
wheels; make can otherwise reuse the old models.
